# One WuWa Mod Manager — Distribution Notice

One WuWa Mod Manager is an unofficial community tool. It is not affiliated with, sponsored by, or endorsed by Kuro Games.

The manager reads folders beneath the WWMI `Mods` directory. Users create and name their own groups and can choose and crop local images for group icons. The application does not include game character portraits.

Portable settings are stored beside the executable in `config/settings.json`. Archive passwords are not saved. Official packages do not contain personal settings. Deleting Mods and preview images requires confirmation and cannot be undone by the application.

The Windows package includes the unmodified 7-Zip 26.03 archive engine. License and source information is in `ThirdParty/7zip/NOTICE.md`; other dependency notices are in `ThirdPartyNotices/README.md`. The application icon and substantial application code were made with generative AI assistance.
